CLAIRMONT - PATCH AWAL ROLE SALES & CUSTOMER

PENTING:
1. Patch ini disusun berdasarkan file clairmont.zip yang sebelumnya diunggah.
2. Pastikan folder clairmont_backup dan export database .sql sudah tersedia.
3. Jangan jalankan migrasi SQL sebelum file PHP pada patch ini disalin ke folder proyek.
4. Salin file/folder di dalam patch ke folder clairmont lokal, pilih Replace jika diminta.
5. Setelah file PHP terganti, buka phpMyAdmin > db_desert > SQL, lalu jalankan migrasi_role_sales_customer.sql.
6. Login Sales diarahkan ke dashboard_admin.php yang sementara dipakai sebagai dashboard operasional Sales. Nama file/struktur menu lama akan dirapikan pada tahap berikutnya.
7. Registrasi publik tetap membuat role customer. Akun Sales dibuat dari akun Admin/Owner lama yang dikonversi oleh migrasi ini.

CATATAN FITUR:
- Sales untuk sementara mewarisi halaman operasional lama (produk, stok, customer, transaksi) agar fungsi lama tidak hilang.
- Tahap berikutnya adalah membuat halaman POS khusus Sales, target penjualan, insentif, reward, dan ulasan pembeli.
- Owner tidak lagi menjadi role login; aturan target/insentif/reward akan dirancang sebagai konfigurasi sistem.
