CLAIRMONT DESSERT - REVISI CUSTOMER WEBSITE

PERUBAHAN UTAMA
- Website Customer hanya digunakan untuk melihat homepage, katalog, kategori, harga, stok, dan detail produk.
- Fitur pemesanan online di sisi Customer dihilangkan: tidak ada keranjang, checkout, pembayaran online, maupun riwayat pesanan Customer.
- Jika ingin membeli produk, pelanggan harus datang langsung ke toko dan melakukan transaksi melalui kasir menggunakan sistem POS.
- Form registrasi Member sekarang meminta nama lengkap, email, nomor telepon, alamat, dan kata sandi.
- Nomor telepon dan alamat disimpan ke kolom no_hp dan alamat pada tabel tb_customer.
- Tampilan Member Lounge dan Profil disesuaikan agar tidak menampilkan informasi pesanan online.
- Fitur POS/kasir tetap dipertahankan dan tidak diubah.

DATABASE
- Struktur tabel tb_customer pada file SQL yang diberikan sudah memiliki kolom no_hp dan alamat.
- Tidak diperlukan penambahan kolom atau perubahan struktur database untuk revisi registrasi ini.
- Pastikan nama database dan konfigurasi koneksi2.php sesuai dengan MySQL lokal.

CARA MEMASANG
1. Backup folder project Clairmont yang lama.
2. Ekstrak ZIP ini.
3. Salin folder clairmont hasil ekstrak ke htdocs, atau salin file revisi ke folder project yang sedang digunakan.
4. Pastikan database db_desert sudah di-import dan konfigurasi koneksi2.php sesuai.
5. Buka dashboard_customer.php melalui browser.

CATATAN PENGUJIAN
- File PHP yang diubah diperiksa menggunakan php -l.
- Integrasi belum diuji langsung melalui browser dengan database MySQL aktif.
