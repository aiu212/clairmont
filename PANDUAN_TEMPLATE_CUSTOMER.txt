PANDUAN REVISI TEMPLATE CUSTOMER CLAIRMONT

Paket ini menggabungkan tampilan Customer Clairmont dengan sistem PHP dan database yang diberikan.

ATURAN WEBSITE CUSTOMER
- Customer atau pengunjung hanya dapat melihat homepage, katalog, kategori, harga, stok, dan detail produk.
- Customer tidak dapat memesan produk melalui website. Fitur keranjang, checkout, pembayaran online, dan riwayat pesanan Customer dinonaktifkan.
- Untuk membeli produk, pelanggan datang langsung ke toko. Pemesanan dan pembayaran dilayani melalui kasir menggunakan POS.
- Registrasi Member memerlukan nama lengkap, email, nomor telepon, alamat, dan kata sandi.

DATABASE
- Tabel tb_customer pada SQL yang diberikan sudah memiliki kolom no_hp dan alamat, sehingga tidak perlu ALTER TABLE.
- Pastikan koneksi2.php menggunakan database db_desert yang benar.

CARA MEMASANG
1. Backup folder proyek lama.
2. Ekstrak ZIP.
3. Salin folder clairmont ke htdocs.
4. Jalankan Apache dan MySQL melalui XAMPP.
5. Buka http://localhost/clairmont/dashboard_customer.php

CATATAN
- Sistem POS pada folder form/pos tetap dipertahankan.
- Dashboard Admin dan Owner tidak sengaja diubah.
- Pengujian sintaks dilakukan dengan php -l. Integrasi browser dan database perlu diuji di komputer lokal.
